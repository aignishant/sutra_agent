## 3 · 📚 Concepts

### OPS-12 — Route to headroom: the math, then the table

**The story.** A hospital has four pharmacies. Each has a window ("serve 5 patients a
minute, 250 a day"). A patient with a routine script can go to any of them; a complex
one needs the specialist pharmacy. A dispatcher at the door counts what each window has
served this minute and today, and points each patient to the shortest safe queue. Nobody
waits at a closed window while three others stand empty.

**The math (one table, four lanes, and why the order is what it is):**

| Lane | Model (pins from Day 9 / tracker) | RPM | RPD | Checked | Role |
| --- | --- | --- | --- | --- | --- |
| `gemini` | `gemini-3.5-flash` | 5 (observed) | TODO (AI Studio) | 2026-08-13 / TODO | reasoning, writer/critic, anything multimodal |
| `gemini-lite` | `gemini-3.5-flash-lite` | TODO | TODO (higher) | TODO | bulk: classifier fallback, judge (Day 67), evals (Phase 12) |
| `groq` | `groq/openai/gpt-oss-120b` (LiteLlm) | **30** | **1,000** | 2026-08-19 | the speed lane: classifier, short structured calls |
| `openrouter` | `openrouter/nvidia/nemotron-3.5-lightning:free` (LiteLlm; Day 9 pin — `TODO(re-verify the :free roster on the day)`) | **20** | **50** | 2026-08-19 | breadth; tiny RPD → last cloud resort for bulk |
| `ollama` | `ollama_chat/llama3.1:8b` (LiteLlm, local) | ∞ | ∞ | — | the floor: everything when clouds are dry; embeddings always (Day 49) |

A full triage run is ~4–5 calls (Day 58's margin): 1 classify + 2 clerks' worth of model
time (the analyst) + writer + critic (+ revisions). Day 66's red team at 5 RPM on one lane
= 70 s pauses. Spread by job: classify → Groq (30 RPM lane, 1 call), reasoning ×3 →
Gemini (5 RPM: three calls fit in one minute), bulk → Lite. The *same* run no longer
touches the 5-RPM ceiling at all; four tickets back-to-back become feasible without a
pause. That's the win: not more quota, **more of the quota you already had**.

**The job table** — a model call is routed by what the *node* is for, not by who wrote
it:

| Job | Preference order (first with headroom wins) | Why this order |
| --- | --- | --- |
| `classify` | groq → gemini-lite → gemini → ollama | short, structured, latency-sensitive; Groq's 30 RPM is made for it; Day 53's LiteLLM-node probe decides if Groq is usable for `output_schema` nodes — if not, gemini-lite leads |
| `reason` | gemini → groq → ollama | writer/critic/analyst want the primary brain; Groq's 120B is a fine substitute; Lite is *not* in the list (quality floor) |
| `bulk` | gemini-lite → openrouter → groq → ollama | judge, evals, nightly digest — volume over polish; OpenRouter's 50/day goes here and nowhere else |
| `embed` | ollama | Day 49: local, unmetered, private (Day 69) |

💡 **Mental model: quota is a *currency with exchange rates*.** One Gemini-Flash call
buys one thoughtful paragraph; one Groq call buys a fast verdict; one Ollama call buys
"good enough, free, offline." The router is a small bureau de change that never lets you
pay for a verdict in paragraphs.

**Two routing points, honestly.** The router can change a request at two moments, and
they differ:

1. **Construction time** (`routed_agent(job, …)`): the agent is *built* with the lane's
   model — `Agent(model="gemini-3.5-flash")` or `Agent(model=LiteLlm("groq/…"))`. This
   is the only way to switch **providers**, because a Groq lane needs a LiteLlm model
   object, not just a name. The graph's agents are built once per process, so this
   decides the *default* lane per job from the ledger's state at build time.
2. **Call time** (plugin `before_model_callback`): the plugin may rewrite
   `llm_request.model` — the *name* sent with this one call. For **same-provider**
   swaps (Gemini Flash ↔ Flash-Lite, both native) that is enough; for cross-provider it
   is not (the model object is already a Gemini client). When the configured lane is
   dry and the only headroom is cross-provider, the plugin cannot swap mid-flight: it
   *says so* (`route_unavailable_mid_flight`) and either proceeds on the configured
   lane (if it still has headroom) or raises `QuotaExhausted`. Never a silent fallback.

(Verify the name-rewrite claim in step 5 — it's a one-call probe. If your installed
version ignores the rewrite, the plugin keeps the *decision* and *billing* roles and the
swap becomes construction-time only; note the margin.)

### ADK-49 — Plugins in anger: decide, rewrite, raise, bill

Day 14's plugin *watched*. Day 21's *replaced an error with an honest fallback*. Day 59's
*raised*. Today's does all of the above in one class, which is what "in anger" means: the
plugin is part of the control path, not the dashboard.

| Door | What the router does there | Return |
| --- | --- | --- |
| `before_model_callback` | look up the agent's job → choose a lane with headroom → if same-provider swap, set `llm_request.model`; if none, `raise QuotaExhausted` (loud; trap #4 honoured — never return a fake response) | `None` (proceed) or raise |
| `after_model_callback` | bill `usage_metadata` to the lane actually used (the watcher's job, now per lane); persist the ledger | `None` |
| `on_model_error_callback` | if a 429 slipped past the ledger's estimate (limits are *our* numbers; the provider's are the truth), mark the lane dry for `retry-after` seconds (the ledger learns), then re-raise by returning `None` — Day 72 adds the honest backoff here | `None` |

Why one plugin instead of three: the meter, the breaker and the router share one state
(the ledger) and must agree on it within the same call; three plugins reading and writing
the same file in sequence is a race and a lie waiting to happen. Retire the watcher and
the breaker *by name* in the doc and in the runner's list; keep their classes for the
record (the repo is the memory).

💡 **Mental model: the meter was a plugin that *looks*; the router is a plugin that
*steers*.** Looking never breaks anything, so nobody tests it. Steering can, so the
router comes with a fake clock and a dry-lane drill.

```python
"""Day 70 — the Quota-Router: route every model call to a lane with headroom.

LANES = what each provider lane is (model string, native or LiteLlm).
JOBS  = for each kind of work, the lanes to try, in order.
choose(job) reads QuotaLedger.remaining() per lane and returns the first
lane with room. routed_agent(job) builds an Agent on that lane
(construction-time routing). QuotaRouterPlugin decides/rewrites/bills/
raises at the model door (call-time routing; supersedes QuotaWatcherPlugin
and QuotaBreakerPlugin).

Importable with no side effects. Demos from the repo root:

    python -m sutra.quota_router table     # lanes, jobs, current headroom (0 quota)
    python -m sutra.quota_router probe     # does llm_request.model rewrite work? (~1 call)
    python -m sutra.quota_router triage    # a routed triage run (~5 calls)
"""
from __future__ import annotations

import sys
from dataclasses import dataclass

from google.adk.agents import Agent
from google.adk.models.lite_llm import LiteLlm                 # Day 9 (verified 08-18)
from google.adk.plugins.base_plugin import BasePlugin          # Day 14 (verified 08-19)

from sutra.logging_setup import get_logger
from sutra.quota import LIMITS, QuotaLedger                    # Day 24 + today's rows

log = get_logger("quota_router")


class QuotaExhausted(RuntimeError):
    """No lane in the job's list has headroom. Loud on purpose (Day 59)."""


@dataclass(frozen=True)
class Lane:
    """One provider lane: a ledger key + the exact pinned model string.

    Attributes:
        key: the QuotaLedger/LIMITS key, e.g. "groq".
        model: the pinned model string (ADK-73: never a default).
        native: True = Gemini-native (plain string to Agent); False = LiteLlm.
    """
    key: str
    model: str
    native: bool

    def adk_model(self):
        """What Agent(model=...) wants: a string for Gemini, a LiteLlm otherwise."""
        return self.model if self.native else LiteLlm(model=self.model)


# Pins: Day 9 (2026-08-18) + tracker. Re-verify rosters on the day (Addendum 02 §3).
LANES: dict[str, Lane] = {
    "gemini":      Lane("gemini",      "gemini-3.5-flash", True),
    "gemini-lite": Lane("gemini-lite", "gemini-3.5-flash-lite", True),
    "groq":        Lane("groq",        "groq/openai/gpt-oss-120b", False),
    "openrouter":  Lane("openrouter",  "openrouter/nvidia/nemotron-3.5-lightning:free", False),
    "ollama":      Lane("ollama",      "ollama_chat/llama3.1:8b", False),
}

# Job -> lanes in preference order (doc section 3 explains each order).
JOBS: dict[str, tuple[str, ...]] = {
    "classify": ("groq", "gemini-lite", "gemini", "ollama"),
    "reason":   ("gemini", "groq", "ollama"),
    "bulk":     ("gemini-lite", "openrouter", "groq", "ollama"),
    "embed":    ("ollama",),
}

# Agent name -> job. Unlisted agents are "reason" (the safe, primary lane).
# TODO(run day: reconcile names with sutra/graph.py, like Day 68's ROLE_OF)
JOB_OF: dict[str, str] = {
    "classify_station": "classify",
    "evidence_analyst": "reason", "draft_writer": "reason", "draft_critic": "reason",
    "sutra_researcher": "reason",
}


def has_headroom(lane_key: str, ledger: QuotaLedger) -> bool:
    """True if the lane can take one more request now, per OUR recorded limits.

    None caps mean "unknown" -> allowed (and logged once); unlimited lanes
    are always open. The provider's 429 is the final word (Day 72).

    Example:
        >>> has_headroom("ollama", QuotaLedger())
        True
    """
    if LIMITS.get(lane_key, {}).get("unlimited"):
        return True
    r = ledger.remaining(lane_key)
    for k in ("rpm_left", "rpd_left"):
        if r[k] is not None and r[k] <= 0:
            return False
    return True


def choose(job: str, ledger: QuotaLedger | None = None) -> Lane:
    """First lane in the job's list with headroom, else raise QuotaExhausted.

    Example (fresh ledger, nothing spent):
        >>> choose("classify").key
        'groq'
    """
    ledger = ledger or QuotaLedger.load()
    for key in JOBS[job]:
        if has_headroom(key, ledger):
            log.info("route", extra={"job": job, "lane": key})
            return LANES[key]
    raise QuotaExhausted(f"no headroom for job={job} in {JOBS[job]}")


def routed_agent(job: str, *, name: str, ledger: QuotaLedger | None = None, **kw) -> Agent:
    """Construction-time routing: build an Agent on the lane choose() picks.

    Example:
        >>> a = routed_agent("classify", name="clf", instruction="Classify.")
        >>> a.model            # a LiteLlm(groq/...) when Groq has headroom
    """
    lane = choose(job, ledger)
    return Agent(name=name, model=lane.adk_model(), **kw)


class QuotaRouterPlugin(BasePlugin):
    """Decide, rewrite, bill, raise - at the model door, for every agent.

    Supersedes QuotaWatcherPlugin (Day 14) + QuotaBreakerPlugin (Day 59).
    Usage:
        Runner(agent=..., plugins=[DataBoundaryPlugin(), QuotaRouterPlugin(), ...])
    """

    def __init__(self, ledger: QuotaLedger | None = None) -> None:
        super().__init__(name="quota_router")
        self.ledger = ledger or QuotaLedger.load()
        self._lane_used: dict[str, str] = {}           # invocation_id -> lane key

    @staticmethod
    def _configured_lane(llm_request) -> Lane | None:
        """Which lane the request is on right now, by model name (best effort)."""
        name = getattr(llm_request, "model", None) or ""
        for lane in LANES.values():
            if lane.model == name or lane.model.endswith("/" + name):
                return lane
        return None

    async def before_model_callback(self, *, callback_context, llm_request):
        """The decision. None = proceed (possibly with a rewritten model name)."""
        job = JOB_OF.get(callback_context.agent_name, "reason")
        current = self._configured_lane(llm_request)
        target = choose(job, self.ledger)              # raises QuotaExhausted if none
        if current is None or current.key == target.key:
            lane = current or target                   # nothing to change
        elif current.native and target.native:         # same provider: rewrite the NAME
            llm_request.model = target.model           # verified field (08-19); probe step 5
            lane = target
            log.info("route_swapped", extra={"from": current.key, "to": target.key, "job": job})
        elif has_headroom(current.key, self.ledger):   # cross-provider, but current still ok
            lane = current
            log.warning("route_unavailable_mid_flight",
                        extra={"configured": current.key, "preferred": target.key,
                               "advice": "construction-time routing decides provider"})
        else:                                          # cross-provider AND current dry
            raise QuotaExhausted(f"lane {current.key} dry; {target.key} needs a rebuild")
        self._lane_used[callback_context.invocation_id] = lane.key
        return None

    async def after_model_callback(self, *, callback_context, llm_response):
        """Bill the call to the lane that served it (the watcher's job, per lane)."""
        lane = self._lane_used.get(callback_context.invocation_id, "gemini")
        usage = getattr(llm_response, "usage_metadata", None)
        self.ledger.record(lane,
                           prompt=(usage.prompt_token_count or 0) if usage else 0,
                           output=(usage.candidates_token_count or 0) if usage else 0,
                           thinking=(getattr(usage, "thoughts_token_count", 0) or 0) if usage else 0)
        self.ledger.save()
        return None

    async def on_model_error_callback(self, *, callback_context, llm_request, error):
        """A 429 the ledger did not predict: the provider knows better. Learn, re-raise."""
        if getattr(error, "code", None) == 429 or "429" in str(error):
            lane = self._lane_used.get(callback_context.invocation_id, "gemini")
            log.warning("route_429_learned", extra={"lane": lane})
            # Day 72 teaches the ledger to mark the lane dry for retry-after seconds.
        return None                                    # None = re-raise (loud; trap #4)
```

## 5 · 💥 Failure lab — the router that trusted its own numbers

> 🎬 **The scene:** the ledger says `groq` has 12 RPM left. Sutra fires the classifier
> at Groq. **429.** Your `LIMITS` row says 30 RPM; Groq's *organization* counter (Addendum
> 02: "per organization") was also being spent by your colleague's notebook. Or the TPM
> cap (8K tokens/min) hit before the RPM cap — a long ticket body, twice. The ledger was
> never wrong about what *you* recorded; it was wrong about *the world*.
> 😬 **The naive fix:** catch the 429 in the router, pick the next lane, retry
> immediately, say nothing. "That's what a router is for."
> 💥 **Why it fails:** silent re-routing hides the fact that your limits table drifted
> from reality — so it drifts further. Worse, the immediate retry on the *next* lane
> under the same burst often 429s too, and you've now spent two lanes' minute budgets
> discovering what one log line would have told you. And a *swallowed* 429 (trap #4) is
> precisely the failure mode the plan's Principle 10 forbids: the run continues as if
> the call were fine when the provider said no.
> 💡 **The insight:** **our ledger is an estimate; the provider's 429 is the truth.**
> On a 429 the router *learns* (mark the lane dry for `retry-after` seconds — Groq
> sends the exact header; Gemini says "retry in Ns" in the message; OpenRouter sends
> `X-RateLimit-Reset` on the error), logs `route_429_learned`, and **re-raises**. Day 72
> builds the honest backoff on top of that — wait what the server said, then escalate —
> and Phase 9's durability means a raised run is a *resumable* run, not a lost one.
> Tonight: note the TPM row in `LIMITS` as a TODO (tokens-per-minute is a second
> window the ledger could track from `usage_metadata`; the design supports it), and
> don't paper over the 429.

## 6 · 🎤 Interview corner

1. **"Tell me about handling rate limits in a multi-agent system."** — Quota is my
   currency: each provider lane has RPM/RPD windows recorded as data with a date, a
   ledger bills every call to a lane and answers "remaining," and a router plugin sends
   each call to the first lane in that *job's* preference list with headroom —
   classifier to Groq's 30-RPM lane, reasoning to Gemini Flash, bulk to Flash-Lite, and
   everything to local Ollama when clouds are dry. A full triage that used to serialize
   on a 5-RPM lane now spreads across two providers and never waits. The decisions are
   unit-tested with a fake clock: minute windows roll, daily caps don't.
2. **"Where in the stack does routing happen?"** — Two places, and I'm honest about the
   difference. Construction time builds the agent on a lane (that's how you switch
   *providers* — Groq needs a LiteLLM model object). Call time, a plugin can rewrite the
   model *name* on the request for same-provider swaps (Flash ↔ Flash-Lite); when the
   only headroom is cross-provider mid-flight it logs that it can't swap and either
   proceeds on the configured lane or raises — never a silent fallback.
3. **"What does the router do on a 429 it didn't predict?"** — Treats the provider as
   the truth: logs that the lane lied to the ledger, marks it dry for the server's stated
   retry window, and re-raises so the durable run can resume later — rather than
   hot-retrying the next lane into the same burst. Swallowing a 429 to keep a run
   "green" is exactly the failure my plan's honesty rule forbids.

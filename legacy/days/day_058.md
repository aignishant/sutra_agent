## 3 · 📚 Concepts

### ADK-41 — Assembly: five stations, four contracts, one honest exit

**The floor plan, drawn once** (memorize this — you will draw it in interviews):

```
             ┌──────────────┐
"4521" ──► intake ──► classify ──► triage_router ──┬──► escalate_lane ──► (human queue)
 (fn)        (fn)      (agent)        (fn)         │
                                                   └──► ┌───────────────────────────┐
                                                        │ evidence: archive ┐       │
                                                        │           (fn)    ├ join ─┼─► draft_review_box ──► finalize
                                                        │           kb ─────┘       │      (nested wf)         (fn)
                                                        └───────────────────────────┘
```

Assembly is not "connect everything" — it is four deliberate decisions:

1. **Typed batons at every seam** (Day 54's relay law, now at scale): `str` → `TicketText`
   → `TriageResult` → `EvidenceBlock` → draft+verdict → `FinalReply`. Write the chain
   down BEFORE wiring; every graph bug you will ever debug is a baton whose sender and
   receiver disagreed.
2. **An escalation lane, wired FIRST.** The router checks `needs_human or severity >= 4`
   *before* any expensive station runs. Two reasons, both principled: blast radius — a
   machine should not draft replies to fires it flagged as fires (Principle 13); and
   economics — escalations cost one call instead of five. The graph's most important
   route is the one where it declines the work. (Phase 9 replaces the lane's stub with a
   real human-in-the-loop gate; the *edge* you draw today is permanent.)
3. **The box drops in whole.** `draft_review_box` — writer, critic, loop, brake — is ONE
   node on this floor. Day 57's seal pays off exactly here: the main line's wiring does
   not know the newsroom exists.
4. **Evidence is parallel and free.** Day 54's two clerks, upgraded: `archive_clerk` now
   calls `sutra/retrieval.py` (the embedding index — #4521 finds #4610 by meaning), the
   KB clerk stays keyword-true, and the join merges once. Zero model calls for the whole
   research floor — the expensive brain is spent only where judgment lives.

💡 **Mental model: a production graph is mostly plumbing around very few brains.** Count
today's stations: seven-ish nodes, TWO of which think (classifier, the box). That ratio —
not the node count — is what "well-engineered agentic system" means. If your ratio
inverts, revisit Day 53's failure lab.

### ADK-42 — Running it: the pipeline as a single observable fact

A pipeline is not "done" when its last node returns — it is done when you can *account*
for the run. Three habits turn a run into a fact (all three are checked in Step 6):

1. **The event stream tells the story in order.** intake's postcard, the classifier's
   verdict, the router's reason, each clerk's report, every critic verdict, finalize's
   stamp. If a station worked and the stream cannot show it, the station did not work
   (Principle 12 — "everything is a trace" was always about THIS day).
2. **`state` is the run's record.** By the end of a run, state carries
   `triage_result`, `evidence`, `rounds`, `shipped_with_flag` — the run's whole case
   file, queryable after the fact. Day 47's persistent sessions mean the case file
   *survives the process* — tomorrow's failure lab and Phase 9's resume both stand on
   that.
3. **Acceptance is run-level.** Node tests (Day 23) prove stations; assembly needs
   pipeline checks: *"every non-escalated run ends with a KB citation"*, *"no run spends
   more than N model calls"*, *"escalated runs produce NO draft"*. Today you check these
   by eye against the stream; Day 59's gate scripts the eyeballing; Phase 12 turns them
   into evals that run nightly. Same checks, ascending automation.

```python
# Composition only: every part below was verified on its own day (53-57).

def intake(node_input: str) -> Event:
    """Station 1: normalize the request into a ticket id + text bundle.

    Example:
        >>> intake("#4521").output.startswith("Ticket #4521")
        True
    """

classify_station = Agent(
    name="classify_station",
    # Groq branch (Day 53 probe PASS): LiteLlm(model="groq/openai/gpt-oss-120b")
    # FAIL branch: the lite lane. Either way: PINNED, never defaulted (ADK-73).
    model="gemini-3.5-flash-lite",
    instruction="""Classify ONE support ticket into the triage form. If no
category fits use 'other' and set needs_human true. Never invent contents.""",
    output_schema=TriageResult,                        # Day 12's form, the graph's baton
)


def triage_router(node_input: TriageResult) -> Event:
    """The most important route: decide whether the MACHINE should continue.

    Escalation is checked before any expensive station runs (blast radius
    AND economics). The verdict rides into state either way — the run's
    record starts here.

    Example:
        >>> triage_router(TriageResult(category="outage", severity=4,
        ...     needs_human=True, notes="payments down")).route
        'ESCALATE'
    """
    hot = node_input.needs_human or node_input.severity >= 4
    return Event(route="ESCALATE" if hot else "HANDLE",
                 state={"triage_result": node_input.model_dump()},
                 output=node_input,
                 message=f"Router: {'ESCALATE' if hot else 'HANDLE'} "
                         f"({node_input.category}, sev {node_input.severity})")


def escalate_lane(node_input: TriageResult) -> Event:
    """The honest exit: hand the case file to humans. NO draft is written.

    Phase 9 replaces this stub with a real approval/HITL gate; the edge
    into it is permanent.
    """
    return Event(output=f"ESCALATED: {node_input.category} sev "
                        f"{node_input.severity} - {node_input.notes}",
                 message="Escalated to the human queue. The machine stops here.")


def research_gate(node_input: TriageResult) -> Event:
    """Adapter station: turn the verdict into the evidence request (a baton
    change, made explicit instead of implicit — assembly rule #1)."""
    tid = "4521"  # placeholder overwritten below — see the state note
    return Event(output=node_input.notes or tid)


def archive_clerk_v2(node_input: str) -> Event:
    """Evidence branch 1, upgraded: MEANING search via Day 49's index."""
    from sutra.retrieval import similar_tickets        # Phase 7's index
    hits = similar_tickets(node_input, top_k=2)        # e.g. #4521 -> #4610
    return Event(output=f"ARCHIVE: {hits}")


def finalize(node_input) -> Event:
    """Station last: stamp the reviewed draft as the pipeline's product."""
    return Event(output=f"REPLY (reviewed): {node_input}",
                 message="Triage complete.")


triage_graph_v1 = Workflow(
    name="triage_graph_v1",
    edges=[
        ("START", intake, classify_station, triage_router),
        (triage_router, {
            "ESCALATE": escalate_lane,                 # one call, honest exit
            "HANDLE":   research_gate,
        }),
        (research_gate, archive_clerk_v2, evidence_join),   # branch 1 (Day 54 join)
        (research_gate, kb_clerk, evidence_join),           # branch 2
        (evidence_join, evidence_analyst, draft_review_box, finalize),
    ],                                                 # the BOX is one station ^
)
```

## 5 · 💥 Failure lab — the demo that only worked on its own ticket

> 🎬 **The scene:** a colleague asks for a demo. Confident from run #1, you type a ticket
> id from *their* system — "8842" — which does not exist in Sutra's archive. intake's
> honest miss ("No ticket with id '8842'") flows to the classifier… which dutifully
> classifies the *error message*: `other`, severity 1, a cheerful draft apologizing for
> an issue nobody has. Five model calls spent producing a polished reply to a ticket that
> does not exist.
> 😬 **The naive fix:** prompt the classifier: "If the text looks like an error message,
> refuse." Prompt-patching a plumbing hole.
> 💥 **Why it fails:** you put a *judgment* station where a *certainty* check belongs —
> Day 53's law, violated in reverse. "Does this ticket exist?" is not a judgment call;
> intake KNEW the answer and whispered it into prose instead of routing on it. Every
> station downstream then did its job perfectly on garbage — pipelines do not average
> away upstream nonsense, they *launder* it into confident output (you met the one-agent
> version of this on Day 4 with ticket 9999; the pipeline version is worse because the
> critic's APPROVED stamp makes it look audited).
> 💡 **The insight:** **validate at the mouth of the pipeline, route on facts, and let
> "no" be a first-class route.** The fix is three lines in intake — return
> `Event(route="NO_SUCH_TICKET")` on a miss — plus one dict edge to an honest reply lane.
> Add it now (it is Day 59's first containment drill anyway). Assembly's deepest rule:
> every station is entitled to assume its input is real, and exactly one station is
> responsible for making that true.

## 6 · 🎤 Interview corner

1. **"Walk me through a multi-agent pipeline you actually built."** — Support-ticket
   triage: intake and routing are deterministic functions; a schema-constrained
   classifier; an escalation route checked before any expensive work; parallel evidence
   gathering (embedding-index archive + KB) meeting at a join; a sealed writer↔critic
   sub-workflow with a typed verdict and a bounded revision loop; deterministic finalize.
   Seven stations, two of which call a model — the ratio is deliberate: judgment where
   it's needed, free exact Python everywhere else. Full run: ~5 model calls, complete
   audit trail in the event stream and session state.
2. **"How do you know the pipeline works — not just each node?"** — Run-level acceptance:
   invariants that quantify over whole runs. Every non-escalated run cites a knowledge-base
   source; escalated runs produce no draft; runs stay under a call budget; the case file
   (classification, evidence, revision count, ship-flag) is complete in state. I proved
   generalization by running a ticket the pipeline was never demoed on — same guarantees,
   different content — and the escalation path was wired and tested FIRST, because the
   most important thing a pipeline can do is decline work it shouldn't touch.
3. **"Where do pipelines like this rot?"** — At the seams and at the mouth. Seams: two
   stations disagreeing about the baton's type — cured by typed contracts at every edge.
   The mouth: unvalidated input flowing in, then being *laundered* by downstream stations
   into confident, reviewed-looking output — cured by validating existence/shape at
   intake and making 'no' a routable outcome, never prose. Both cures are structural;
   neither is a prompt.

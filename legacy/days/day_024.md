## 3 · 📚 Concepts

### AG-11 — Token economics: the three currencies

**The prepaid-phone story.** Sutra's brain runs on a prepaid plan: so many calls per
minute (RPM), so many per day (RPD), so many words per call (token limits). No overdraft —
the network just refuses (429). Anyone who's rationed a prepaid phone knows the three
skills: know the tariff, meter the spending, don't redial a busy line in a loop.

First, the tariff sheet — what one model call actually bills:

| Meter | What it counts | Why it's expensive |
| --- | --- | --- |
| **Input (prompt) tokens** | everything you send: instruction, tools, state facts, history, question — the whole Day 19 anatomy | resent **every call**; in a loop, history makes this grow per step |
| **Output (candidates) tokens** | text the model writes | generated one at a time — the latency driver; on paid tiers, priced several× input |
| **Thinking tokens** | internal reasoning on thinking models — **you never see them as text** | billed like output; our pinned `gemini-3.5-flash` thinks *by default* |
| **Requests** | the call itself, regardless of size | the free tier's hardest wall: 5 RPM observed; RPD caps the whole day |

Then the multiplication table that turns tariffs into engineering (do these aloud):

1. **The loop multiplier** (Day 3's law with a price tag): a 6-step agent run resends
   the transcript 6 times. If the packed context is 2,000 tokens, that's ~12,000 input
   tokens *plus* 6 requests — for **one** user question.
2. **The day budget**: at (say) 250 RPD, a 6-request question shape means **~40 user
   questions per day**. Not a guess — a division. This is why Day 19's packing and
   Day 20's compaction are capacity planning, not tidiness.
3. **The invisible line item**: thinking tokens inflate `total_token_count` beyond
   `prompt + candidates`. A one-sentence reply can carry hundreds of thinking tokens
   behind it (§5 stages exactly this ambush).

💡 **Mental model: a model call is a metered international phone call — you pay to talk
(input), pay to listen (output), sometimes pay for the other side to *think* (thinking
tokens), and the line has a per-day allowance. Agents redial constantly.**

The professional reflex: **estimate before you build** (steps × context weight × calls per
question, against the tariff), **meter while you run** (today's ledger), **route by
headroom** (Day 70). Dollars-vs-quota is only a unit change — the reflex transfers to any
paid tier unchanged.

### OPS-07 — The accountant: counters that survive

Where do true numbers come from? Not from guessing: ADK stamps every model-call event with
`usage_metadata` — `prompt_token_count`, `candidates_token_count`, `total_token_count`
(and `thoughts_token_count` when the model thinks). Day 22's logbook already glimpsed it;
today we *account* for it.

Design of `sutra/quota.py`, driven by four requirements:

| Requirement | Design answer |
| --- | --- |
| RPM needs a rolling 60-second view | keep a deque of recent request timestamps; drop entries older than 60 s |
| RPD outlives the process (restarting Python must NOT reset the day!) | persist the ledger as JSON in `logs/quota.json`; reload on start; roll over when the date changes |
| Multiple providers, one accountant | counters keyed by provider name (`gemini`, `gemini-lite`, `groq`, `openrouter`, `ollama`) |
| Spending decisions need one question | `remaining(provider)` → requests left this minute / today, from *recorded limits* (looked up, dated — never invented) |

Two boundaries keep it honest. **The ledger measures; it doesn't yet enforce** — warnings
today, routing decisions on Day 70 (measure first, then act — the same order as Days 19→20).
And **limits are data, not code**: they live in a small table with a `checked` date,
because free tiers move (Dec 2025 precedent) and an invented ceiling is worse than none.

```python
"""Day 24 — the accountant: token & request accounting in quota currency.

Counts requests (RPM/RPD) and tokens per provider, persists to
logs/quota.json so the DAY survives process restarts, and answers
"what's left?" — the question Day 70's Quota-Router will ask per call.
Measures only; enforcement policy arrives with the router.

    python -m sutra.quota meter    # one REAL triage call, fully billed (~2 calls)
    python -m sutra.quota report   # read the ledger; spends NOTHING
"""
from __future__ import annotations

import json
import sys
import time
from collections import deque
from dataclasses import dataclass, field
from datetime import date
from pathlib import Path

from sutra.logging_setup import configure, get_logger

log = get_logger("quota")
LEDGER_FILE = Path("logs") / "quota.json"            # gitignored shelf (Day 22)

# Limits are DATA with a date — looked up, never invented (Principle 7).
# Re-check on phase gates; update `checked` when you do.
LIMITS = {
    #  provider     rpm                 rpd                          checked
    "gemini":      {"rpm": 5,           "rpd": None,                 "checked": "2026-08-13"},
    # rpm=5 observed in 429 metadata (PACKAGES.md Day 2 row).
    # TODO(read RPD for your project in the AI Studio rate-limit view, then fill it in)
    "gemini-lite": {"rpm": None,        "rpd": None,                 "checked": None},
    # TODO(AI Studio rate-limit view for gemini-3.5-flash-lite)
}


@dataclass
class QuotaLedger:
    """Per-provider request & token accounting with a persistent day file.

    Example:
        >>> ledger = QuotaLedger.load()
        >>> ledger.record("gemini", prompt=1200, output=45, thinking=310)
        >>> ledger.remaining("gemini")["rpm_left"]   # 5-RPM lane, 1 spent
        4
        >>> ledger.save()                            # day totals survive exit
    """

    day: str = field(default_factory=lambda: date.today().isoformat())
    requests_today: dict[str, int] = field(default_factory=dict)
    tokens_today: dict[str, dict[str, int]] = field(default_factory=dict)
    # rolling minute window: timestamps of recent requests, per provider
    _minute: dict[str, deque] = field(default_factory=dict, repr=False)

    # ---------- persistence: the day must outlive the process ----------
    @classmethod
    def load(cls) -> "QuotaLedger":
        """Reload today's ledger from disk; roll over if the date changed."""
        if LEDGER_FILE.exists():
            raw = json.loads(LEDGER_FILE.read_text(encoding="utf-8"))
            if raw.get("day") == date.today().isoformat():   # same day -> continue it
                return cls(day=raw["day"],
                           requests_today=raw["requests_today"],
                           tokens_today=raw["tokens_today"])
            log.info("quota_day_rollover", extra={"old_day": raw.get("day")})
        return cls()                                     # fresh day, zero balances

    def save(self) -> None:
        """Write the day's balances to disk (call after each record batch)."""
        LEDGER_FILE.parent.mkdir(exist_ok=True)
        LEDGER_FILE.write_text(json.dumps({
            "day": self.day,
            "requests_today": self.requests_today,
            "tokens_today": self.tokens_today,
        }, indent=2), encoding="utf-8")

    # ---------- recording: one line per model call ----------
    def record(self, provider: str, *, prompt: int = 0, output: int = 0,
               thinking: int = 0) -> None:
        """Bill one model call to a provider's meters.

        Args:
            provider: lane name, e.g. "gemini" or "gemini-lite".
            prompt: prompt_token_count from usage_metadata.
            output: candidates_token_count.
            thinking: thoughts_token_count (thinking models; else 0).
        """
        now = time.monotonic()
        window = self._minute.setdefault(provider, deque())
        window.append(now)                               # one request, timestamped
        while window and now - window[0] > 60:           # slide the minute window
            window.popleft()

        self.requests_today[provider] = self.requests_today.get(provider, 0) + 1
        bucket = self.tokens_today.setdefault(
            provider, {"prompt": 0, "output": 0, "thinking": 0})
        bucket["prompt"] += prompt                       # the three token meters
        bucket["output"] += output
        bucket["thinking"] += thinking
        log.info("quota_record", extra={"provider": provider, "prompt": prompt,
                                        "output": output, "thinking": thinking,
                                        "rpm_used": len(window),
                                        "rpd_used": self.requests_today[provider]})

    # ---------- the question everything else will ask ----------
    def remaining(self, provider: str) -> dict:
        """How much headroom is left, per recorded limits (None = unknown).

        Returns:
            {"rpm_left": int|None, "rpd_left": int|None,
             "rpm_used": int, "rpd_used": int}
        """
        limits = LIMITS.get(provider, {})
        rpm_used = len(self._minute.get(provider, ()))
        rpd_used = self.requests_today.get(provider, 0)
        rpm_cap, rpd_cap = limits.get("rpm"), limits.get("rpd")
        result = {
            "rpm_used": rpm_used,
            "rpd_used": rpd_used,
            "rpm_left": None if rpm_cap is None else max(0, rpm_cap - rpm_used),
            "rpd_left": None if rpd_cap is None else max(0, rpd_cap - rpd_used),
        }
        if result["rpm_left"] == 0:                      # measured, not enforced (yet):
            log.warning("quota_rpm_exhausted", extra={"provider": provider})
        return result


def meter() -> None:
    """One real triage run, every event billed to the ledger. (~2 calls)"""
    configure()
    import asyncio
    from google.adk.runners import Runner
    from google.adk.sessions import InMemorySessionService
    from google.genai import types
    from sutra.agent import sutra_triage                 # the Day 5 agent (pinned gemini)
    from sutra.config import load_env

    load_env()
    ledger = QuotaLedger.load()                          # continue today's balances
    service = InMemorySessionService()
    runner = Runner(agent=sutra_triage, app_name="sutra", session_service=service)
    asyncio.run(service.create_session(app_name="sutra", user_id="priya",
                                       session_id="s1"))
    message = types.Content(role="user", parts=[types.Part(
        text="One line: likely cause for 'users keep getting logged out'?")])

    async def go() -> None:
        async for event in runner.run_async(user_id="priya", session_id="s1",
                                            new_message=message):
            usage = getattr(event, "usage_metadata", None)
            if usage:                                    # a model call happened -> bill it
                ledger.record(
                    "gemini",
                    prompt=usage.prompt_token_count or 0,
                    output=usage.candidates_token_count or 0,
                    thinking=getattr(usage, "thoughts_token_count", 0) or 0,
                )
            if event.is_final_response() and event.content:
                print("reply:", event.content.parts[0].text.strip())

    asyncio.run(go())
    ledger.save()                                        # the day survives us
    _print_bill(ledger)


def report() -> None:
    """Read the ledger from disk and print the bill. Spends NOTHING."""
    configure()
    _print_bill(QuotaLedger.load())


def _print_bill(ledger: QuotaLedger) -> None:
    """Human-readable statement of today's account."""
    print(f"\n=== quota ledger — {ledger.day} ===")
    for provider, tokens in ledger.tokens_today.items():
        reqs = ledger.requests_today.get(provider, 0)
        print(f"{provider:12} requests={reqs:4}  prompt={tokens['prompt']:6}  "
              f"output={tokens['output']:6}  thinking={tokens['thinking']:6}")
        info = ledger.remaining(provider)
        print(f"{'':12} rpm {info['rpm_used']}/{LIMITS.get(provider, {}).get('rpm')}"
              f"   rpd {info['rpd_used']}/{LIMITS.get(provider, {}).get('rpd')}")
    if not ledger.tokens_today:
        print("(no spending recorded today)")


def main() -> None:
    """Demo dispatcher — house pattern."""
    demos = {"meter": meter, "report": report}
    name = sys.argv[1] if len(sys.argv) > 1 else "report"
    if name not in demos:
        print(f"usage: python -m sutra.quota [{'|'.join(demos)}]")
        raise SystemExit(2)
    demos[name]()


if __name__ == "__main__":
    main()
```

"""Day 24 — the accountant's arithmetic, pinned before first use."""
from __future__ import annotations

from sutra.quota import LIMITS, QuotaLedger


def test_record_accumulates_all_three_meters() -> None:
    ledger = QuotaLedger()
    ledger.record("gemini", prompt=100, output=20, thinking=30)
    ledger.record("gemini", prompt=50, output=10, thinking=0)
    assert ledger.requests_today["gemini"] == 2
    assert ledger.tokens_today["gemini"] == {
        "prompt": 150, "output": 30, "thinking": 30}


def test_remaining_subtracts_from_recorded_rpm_limit() -> None:
    ledger = QuotaLedger()
    for _ in range(2):
        ledger.record("gemini")
    info = ledger.remaining("gemini")
    assert info["rpm_used"] == 2
    assert info["rpm_left"] == LIMITS["gemini"]["rpm"] - 2


def test_unknown_limits_stay_none_never_invented() -> None:
    ledger = QuotaLedger()
    ledger.record("gemini-lite")
    info = ledger.remaining("gemini-lite")
    assert info["rpd_left"] is None            # unknown ceiling -> None, not a guess
                                               # (Principle 7 as a unit test)

def test_day_rollover_resets_balances(tmp_path, monkeypatch) -> None:
    import sutra.quota as quota_mod
    monkeypatch.setattr(quota_mod, "LEDGER_FILE", tmp_path / "quota.json")
    old = QuotaLedger(day="2000-01-01")        # a ledger from the distant past
    old.record("gemini", prompt=999)
    old.save()
    fresh = QuotaLedger.load()                 # loading TODAY must not inherit it
    assert fresh.requests_today == {}          # new day, clean slate

## 5 · 💥 Failure lab — the invisible line item

> 🎬 **The scene:** you estimate tomorrow's workload like a pro: "replies are ~40 output
> tokens, prompts ~1,500 — call it 1,540 total per call; our token-per-minute headroom
> fits easily." The estimate uses the two numbers everyone can *see*: what you send, what
> you read.
> 😬 **The naive fix:** ship the estimate. It's arithmetic — what could be wrong?
> 💥 **Why it fails:** the meter reads three or four times your estimate by lunch. The
> gap is `thoughts_token_count` — the pinned `gemini-3.5-flash` is a **thinking-by-default**
> model (your own CHANGELOG says so), and it reasons *before* every visible word. Those
> reasoning tokens never appear in the reply; they appear only in `usage_metadata`, billed
> like output. Your one-line answer carried hundreds of invisible tokens behind it — per
> call, per step, per question. An estimate built from visible text alone systematically
> undercounts a thinking model, and "systematically undercounts" on a free tier means
> "dark before dinner."
> 💡 **The insight:** **bill from the meter, never from the transcript.** `usage_metadata`
> is ground truth; visible text is marketing. Budget thinking models with a measured
> thinking multiplier (today you recorded your first real one — that's the number your
> estimates use now), and when a job doesn't need deep reasoning, route it to the lite
> lane, where the thinking bill is small or absent. Measure (today) → route (Day 70).

## 6 · 🎤 Interview corner

1. **"How do you think about cost in an LLM system?"** — In three currencies per call —
   input tokens (the whole assembled context, resent every loop step), output tokens
   (generation, the latency driver), and on thinking models an invisible reasoning line
   item — all bounded by request quotas, RPM and RPD. I've run a desk where the budget was
   denominated purely in quota: the discipline is estimate before building (steps ×
   context weight against the tariff), meter every call from `usage_metadata` into a
   persistent per-provider ledger, and route by headroom. Swap quota for dollars and
   nothing about the method changes — only the unit.
2. **"Tell me about a cost surprise."** — The thinking bill: our pinned Flash model
   reasons by default, so a one-sentence reply carried hundreds of `thoughts_token_count`
   tokens that never appear as text. Any estimate built from visible transcript length
   undercounts several-fold. Fix: bill only from usage metadata, keep a measured thinking
   multiplier per model, and push non-reasoning jobs to a lite model where that line item
   collapses.
3. **"Why does your quota ledger persist to disk?"** — Because the binding budget is
   *daily* and processes restart many times a day; an in-memory counter resets to zero
   and cheerfully authorizes spending that the provider will 429. The ledger reloads
   today's balances on start and rolls over on date change — and there's a unit test that
   proves a stale day resets while a same-day restart doesn't. Budgets that don't survive
   restarts are decorations.

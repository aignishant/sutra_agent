## 3 · 📚 Concepts

### ADK-09 — LiteLLM: one plug for every socket

**The travel-adapter story.** You land in a new country and your laptop plug does not fit
the wall. You do not rewire the laptop. You do not buy a new laptop per country. You carry
one **universal travel adapter**: laptop side always the same, wall side swappable.

Model providers are wall sockets. Google's socket speaks the Gemini API. Groq's speaks an
OpenAI-shaped API. OpenRouter speaks its own aggregated shape. Ollama listens on
`localhost`. Your agent is the laptop — and **LiteLLM is the adapter**.

| Travel story | Our system | Technical name |
| --- | --- | --- |
| The laptop that never changes | `Agent(name="sutra_triage", instruction=..., tools=...)` | the agent definition |
| The universal adapter | `LiteLlm(model="<provider>/<model>")` | `google.adk.models.lite_llm.LiteLlm` |
| The country prefix on the adapter dial | `groq/`, `openrouter/`, `ollama_chat/` | the LiteLLM provider prefix |
| Plugging straight into a native socket | `model="gemini-3.5-flash"` (a plain string) | ADK's native Gemini path — no adapter needed |

💡 **Mental model: ADK speaks Gemini natively; LiteLLM is a universal translator that makes
every other provider *look like* one API.** One import, four providers, zero dollars.

The deep point is **architectural, not mechanical**: because the model is a *parameter*,
"which brain?" becomes a **configuration decision, not a rewrite**. That is what makes Day
70's Quota-Router possible — a plugin that answers "which provider has headroom *right
now*?" per call. Today builds the sockets; Day 70 builds the switchboard.

### ADK-08 — Ollama: the employee who never goes home

**Simple version:** Ollama runs open-weight models (Llama, Qwen, Gemma…) **on your own
machine**. No key, no cloud, no rate limit, no one reading your prompts.

Concrete example of why Sutra needs this lane: it is 23:40, the nightly job (Day 73) is
mid-run, and all three cloud providers are rate-limited or down. The queue does not care.
`ollama_chat/llama3.1:8b` answers — slower, a little less brilliant, **but present**. In
the quota economy (§4 of the plan), *guaranteed availability at zero quota* is a
first-class asset, not a toy.

The honest trade-offs, so you can defend them in an interview:

| Lane | Brains | Speed | Quota | Privacy |
| --- | --- | --- | --- | --- |
| Gemini (`gemini-3.5-flash`) | best in our lineup | good | 5 RPM observed | prompts may train Google's models (free tier) |
| Groq (open-weight, custom chips) | good | **absurdly fast** | ~30 RPM class, per org | cloud |
| OpenRouter `:free` | varies by model | varies | **tiny** (~20 RPM / ~50 RPD floor) | cloud, varies |
| Ollama (local) | smallest | slowest | **none** | **total** — nothing leaves the laptop |

```python
"""Day 9 — one agent, four free providers, via LiteLLM.

The agent definition (name, instruction) never changes. Only the `model`
parameter changes: a plain string for Gemini (native), or a LiteLlm wrapper
for everyone else. That is ADK-09 in one sentence.

Importable with no side effects. Run demos from the repo root:

    python -m sutra.providers gemini      # the control group (~1 Gemini call)
    python -m sutra.providers groq        # the speed lane
    python -m sutra.providers openrouter  # the breadth lane (tiny quota - sparingly!)
    python -m sutra.providers ollama      # the offline lane (start `ollama serve` first)
"""
from __future__ import annotations

import sys
import time

from google.adk.agents import Agent                    # the agent class (Day 5)
from google.adk.models.lite_llm import LiteLlm         # the universal adapter (verified 2026-08-18)
from google.adk.runners import InMemoryRunner          # runner shape seen on adk.dev/plugins/
from google.genai import types                         # Content/Part, same as Day 4

from sutra.config import load_env                      # .env loader (Day 1)
from sutra.loop import TRIAGE_QUESTION                 # the Day 3 headline question, reused

# ---------------------------------------------------------------------------
# The pin table, as code. Each entry: how this lane's model is expressed.
# A plain string  -> ADK's native Gemini path (no adapter).
# A LiteLlm(...)  -> the adapter, with the provider prefix on the dial.
# Pins found 2026-08-18 - RE-VERIFY per the doc's section 3 before running.
# ---------------------------------------------------------------------------
PROVIDERS: dict[str, object] = {
    "gemini": "gemini-3.5-flash",                                   # native socket (pinned Day 5, ADK-73)
    "groq": LiteLlm(model="groq/openai/gpt-oss-120b"),              # speed lane
    "openrouter": LiteLlm(                                          # breadth lane -
        model="openrouter/nvidia/nemotron-3.5-lightning:free"       # ':free' suffix is LAW
    ),                                                              # (missing it can bill!)
    "ollama": LiteLlm(model="ollama_chat/llama3.1:8b"),             # offline lane, localhost
}

# One instruction for all four lanes - the agent does not know or care
# which brain answers. (Persona work from Day 6, honesty rule from Day 3.)
INSTRUCTION = """You are Sutra, a support-ticket triage assistant.
Answer briefly. Never invent ticket contents or KB articles - if you do
not know, say so."""


def make_agent(lane: str) -> Agent:
    """Build the same triage agent on a chosen provider lane.

    Args:
        lane: one of "gemini", "groq", "openrouter", "ollama".

    Returns:
        An Agent whose only difference across lanes is its `model`.

    Example:
        >>> agent = make_agent("groq")         # same brain-holder...
        >>> agent.name
        'sutra_triage_groq'                    # ...different brain
    """
    return Agent(
        name=f"sutra_triage_{lane}",     # unique name per lane (names must be unique)
        model=PROVIDERS[lane],           # THE line of the day: model is just a parameter
        instruction=INSTRUCTION,         # identical everywhere - that is the point
    )


def run_once(agent: Agent, question: str) -> tuple[str, float]:
    """Ask one question, return (final_text, seconds) - our stopwatch harness.

    Uses the Day 8 runner pattern: an InMemoryRunner drives the agent and
    yields 2.x events; `event.is_final_response()` (adk.dev/events/,
    2026-08-18) marks the answer. Trap #2 reminder: never copy 1.x event
    field names from old tutorials.

    Args:
        agent: any Agent from make_agent().
        question: plain-text user message.

    Returns:
        (answer text, wall-clock seconds for the whole run).

    Example:
        >>> text, secs = run_once(make_agent("gemini"), "Say OK.")
        >>> print(f"{secs:.1f}s", text[:20])
        1.2s OK
    """
    runner = InMemoryRunner(agent=agent)                 # bundles agent + in-memory services
    # TODO(session/run kwargs: confirm exact create_session/run signature at
    # adk.dev/api-reference/python/ on the day - Day 8's doc has the verified shape)
    session = runner.session_service.create_session_sync(
        app_name=runner.app_name, user_id="day9"         # one throwaway session per run
    )
    message = types.Content(                             # same Content shape as Day 4
        role="user", parts=[types.Part(text=question)]
    )
    start = time.perf_counter()                          # stopwatch on
    final = ""                                           # will hold the answer text
    for event in runner.run(                             # events stream out as they happen
        user_id="day9", session_id=session.id, new_message=message
    ):
        if event.is_final_response() and event.content:  # the 2.x "this is the answer" check
            final = "".join(                             # stitch text parts together
                p.text or "" for p in event.content.parts
            )
    return final.strip(), time.perf_counter() - start    # stopwatch off


def demo(lane: str) -> None:
    """Run the triage question down one lane and print answer + latency.

    Usage:  python -m sutra.providers <lane>       (1 model call on that lane)
    """
    agent = make_agent(lane)                             # same agent, chosen socket
    print(f"lane: {lane}  model: {PROVIDERS[lane]}")     # show which brain is on duty
    text, secs = run_once(agent, TRIAGE_QUESTION)        # ask the Day 3 question
    print(f"latency: {secs:.2f}s")                       # the number for your table
    print(f"answer:  {text}")                            # the quality for your table


def main() -> None:
    """Tiny demo dispatcher - mirrors Day 2/3/4's pattern."""
    lane = sys.argv[1] if len(sys.argv) > 1 else "gemini"
    if lane not in PROVIDERS:
        print(f"usage: python -m sutra.providers [{'|'.join(PROVIDERS)}]")
        raise SystemExit(2)
    load_env()                                           # keys from .env, never from code
    demo(lane)


if __name__ == "__main__":
    main()
```

## 5 · 💥 Failure lab — the suffix that bills

> 🎬 **The scene:** OpenRouter's catalog is a candy store. You want to try a bigger model
> on the Critic idea you have for Phase 8, so you copy a model ID from a blog post:
> `openrouter/some-lab/shiny-model-70b`. It even runs.
> 😬 **The naive fix:** "It answered, so it must be on the free tier — OpenRouter knows I
> have no credits."
> 💥 **Why it fails:** on OpenRouter, **free is a variant, not a default**. The `:free`
> suffix selects the zero-cost route; the same ID without it selects the *paid* route.
> With no credits you get an HTTP 402/credits error — annoying but harmless. The dangerous
> day is the day an account *has* credits (a future employer's key, a friend's key): the
> exact same line of code silently spends real money. A model string is a **billing
> decision wearing a config costume**.
> 💡 **The insight:** rules that must hold forever belong in **lint, not memory**. Day 31's
> `make check` gains exactly this rule: any `openrouter/` string in the repo must end in
> `:free`, or the build fails. Addendum 02 §7 wrote the rule; today you felt why.

Try it (safe with an empty-credit account): change the model string to strip `:free`, run
the demo, read the error, **put the suffix back**. Observed, not asserted.

## 6 · 🎤 Interview corner

1. **"How would you design an agent system that isn't locked to one model vendor?"** —
   Make the model a constructor parameter, not an assumption. In ADK the same agent takes
   either a native Gemini string or a `LiteLlm("provider/model")` wrapper; I ran one triage
   agent across Gemini, Groq, OpenRouter, and a local Ollama model with zero changes to
   instructions or tools, and benchmarked them (latency/quality/quota). Vendor choice then
   becomes routing policy — I later built a quota-aware router on the same seam.
2. **"Why would you ever run a *local* model when free cloud tiers exist?"** — Three
   reasons I can defend with a demo: availability (my local lane answered with WiFi off —
   clouds rate-limit and go down), privacy (nothing leaves the machine; free cloud tiers
   may train on your data), and floor-cost (zero marginal quota, which matters when your
   nightly batch job runs at 2 a.m. against exhausted cloud quotas).
3. **"What's the operational risk of free-tier models?"** — The roster moves under you. In
   my own project, the provider lineup changed materially within *six days* of writing the
   plan (Groq's production models rotated; OpenRouter's free floor shrank). Defenses:
   pin explicit dated model strings, re-verify at every phase gate, and lint anything
   billing-sensitive (the `:free` suffix rule) so drift fails the build instead of the
   bank account.
